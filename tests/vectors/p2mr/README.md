# BIP 360 P2MR construction vectors

Shared fixtures for **Pay-to-Merkle-Root (P2MR)** script-tree construction and
control blocks under BIP 360: given a script tree, what leaf hashes, merkle
root, `scriptPubKey`, bech32m address, and script-path control blocks should
you get?

These files are **not** the signature algorithm test data (known-good Schnorr,
ML-DSA, or SLH-DSA keys and signatures). That material lives under
`tests/vectors/fixtures/` and is regenerated into language-specific copies by
a script; see [`../README.md`](../README.md). Everything in this directory is
hand-written JSON that languages load directly.

## Single load path

All languages and the workshop load construction fixtures from:

**`tests/vectors/p2mr/fixtures/`**

There is no second copy under `examples/bip360-workshop/`. Workshop Rust tests
use `include_str!` to this directory; Python / Node / hermetic Rust resolve
relative to the repo root (`CARGO_MANIFEST_DIR`, `__dirname`, or
`default_fixtures_dir()`).

## Consumers

- Python: `python/p2mr/` + `python/tests/test_p2mr_construction.py`
- Hermetic Rust: `tests/p2mr_construction.rs`
- Node: `nodejs/tests/p2mr_construction.test.ts`
- Workshop Rust: `examples/bip360-workshop/rust/tests/p2mr_{,pqc_}construction.rs` (loads this directory)
- Workshop Python: `examples/bip360-workshop/python/p2mr.py` (loads this directory)
- Workshop archival material (spend demos, signet utils, etc.): `examples/bip360-workshop/` (no construction JSON copies)

### Which fixture is the multi-language bar?

Both fixtures use the **same full expected-value checks** in hermetic Python,
Rust, and Node (leaf hashes, merkle root, `scriptPubKey`, bech32m address,
script-path control blocks including `leafVersion`).

| Fixture | CI role |
|---------|---------|
| `p2mr_construction.json` | **Required** — classic pure construction ref |
| `p2mr_pqc_construction.json` | **Required** — P2MR/PQC construction ref (same checks; includes non-standard leaf versions such as `0xfa` / control-block first byte) |

## Updating

When BIP 360 construction semantics or official vectors change, replace the
JSON under `fixtures/` and re-run language e2e. These are **not** generated by
`scripts/sync-golden-vectors.py`. Do not reintroduce copies under the workshop.
